# Console Mode

macOS 26 quick-capture note console. Summon with **⌃⇧`** (Control–Shift–backtick), type a line, press Return.

## Requirements

- macOS 26+
- Xcode 26 / Swift 6.3

## Build & run

```bash
make run
```
